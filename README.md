### 🏦 은행의 계좌 및 이체 시스템
> 토이 프로젝트 | 2023.01 ~ 2023.03  
> `Java` `Spring` `MySQL` `JPA`

#### 🔹 활동 배경:
금융 서비스의 핵심 기능인 계좌 관리와 이체 프로세스를 직접 구현하며,  
실제 서비스 환경에서 요구되는 데이터 정합성, 장애 대응, 그리고 시스템 설계 역량을 경험하고자 프로젝트를 진행했습니다.  
특히 서로 다른 두 금융 서비스 간 계좌 이체가 이루어지는 상황을 가정하여, 안정적인 거래 처리 구조를 구현하는 것을 목표로 했습니다.

#### 🔹 맡은 역할:
- 계좌 생성 및 관리 기능 설계 및 구현
- 은행 간 이체 프로세스 설계
- 데이터베이스 모델링 및 트랜잭션 처리 로직 구현
- 장애 상황 대응 시나리오 설계 및 데이터 정합성 검증
- 팀 내 기술 공유 및 문제 해결 방향 제시

#### 🔹 구체적인 활동:
- 서로 다른 두 서비스 간 책임을 명확히 정의하여 유지보수성과 확장성을 고려한 구조 설계
- 비동기 메시지 처리, API 호출 프로토콜 등 은행 간 통신 구조 학습 및 적용
- 입금 은행이 일정 시간 동안 출금 은행의 응답을 대기해야 하는 상황을 고려하여 타임아웃 및 예외 처리 로직 설계
- 트랜잭션 추적을 위한 GUID 기반 식별자 설계 및 장애 복구 시 데이터 추적 가능 구조 구현
- 사용자 사용 패턴을 고려하여 거래 내역 조회 중심으로 데이터 모델링 수행
- 애플리케이션 메모리 사용량과 데이터 조회 성능을 고려한 ERD 설계
- 장애 발생 시 두 서비스 간 데이터 불일치 문제를 최소화하기 위한 정합성 검증 로직 구현

#### 🔹 성과 및 배운 점:
- 단순 기능 구현을 넘어 금융 시스템에서 요구되는 데이터 정합성과 안정성의 중요성을 체감
- 장애 상황에서 문제를 빠르게 공유하고 원인을 분석하는 협업 프로세스 경험
- 지속적인 상태 공유와 기술 논의를 통해 시스템 문제를 단계적으로 해결하는 경험 축적
- 실제 서비스 수준의 예외 처리 및 장애 복구 관점을 고려한 설계 역량 향상
