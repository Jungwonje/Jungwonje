### 🔍 상품리뷰분석 Agent
> 미니 프로젝트(3차) | 2026.05.11 ~ 2026.05.14  
> `OpenAI GPT` `LangSmith` `SQLite` `Streamlit` `LangGraph & LangChain`

#### 🔹 활동 배경:
상품 구매 전 리뷰가 소비자의 의사결정에 큰 영향을 미치지만, 방대한 리뷰 데이터 속에서 가짜 리뷰, 편향된 리뷰,
비정형 텍스트 정보를 사람이 직접 판단하기에는 시간, 노력 측면에서 한계가 있습니다.
이에 저희 조는 LLM 기반 Agent 시스템을 활용하여 상품 리뷰를 자동 분석하고, 리뷰 신뢰도 및 감성 분석 결과를 시각적으로
제공하는 AI 서비스를 구현하고자 프로젝트를 진행했습니다.
또한 Agent실행 흐름을 실시간으로 추적하고 성능을 개선할 수 있도록 LangSmith 기반 모니터링 환경 구축을 주요 목표로 설정했습니다.

#### 🔹 맡은 역할:
- Streamlit을 통한 대시보드 기능 구현
- 발표 PPT 제작

#### 🔹 구체적인 활동:
- 대시보드에서 리뷰를 선택 시 해당 리뷰에 대한 분석결과와 피드백을 텍스트 형태로 제공
- 대시보드에서 리뷰를 선택 시 해당 리뷰에 대한 긍부정 데이터프레임과 막대 그래프를 제공함으로써 시각적 효과 구현
- 현재 리뷰나 과거 리뷰를 구분하지 않고 선택한 리뷰에 대한 전체 대시보드 동기화 작업
- 선택 리뷰에 대한 별점 및 긍부정 비율 시각적으로 구현
- LangSmith와 Streamlit을 통한 연계 및 실시간 추적

#### 🔹 성과 및 배운 점:
- 단순히 LLM API를 호출하는 수준을 넘어, **LangGraph 기반 Agent Workflow와 LangSmith 기반 실행 모니터링 환경**을 직접 경험하며  
  AI 서비스에서 Prompt 흐름 관리와 실행 로그 추적의 중요성을 체감할 수 있었습니다.

- Streamlit 기반 대시보드를 구현하며, 단순 데이터 출력이 아닌 **사용자에게 시각적으로 최적화된 형태로 데이터를 시각화하고 전달하는 UI/UX 설계 역량**을 향상시킬 수 있었습니다.

- 리뷰 선택에 따라 전체 대시보드가 실시간으로 동기화되도록 구현하는 과정에서,  
  **상태 관리(State Management)와 데이터 흐름 설계의 중요성**을 실무 관점에서 경험할 수 있었습니다.

- 팀 프로젝트 과정에서 코드 병합 및 기능 통합 과정의 어려움을 경험하며,  
  **역할 분담, 일정 관리, 지속적인 커뮤니케이션의 중요성**을 체감할 수 있었습니다.

#### 🔹 직무 연관성 강조:
본 프로젝트를 통해 **비정형 텍스트 데이터 분석, LLM 기반 Agent 설계, Prompt Engineering, 실행 로그 모니터링, 데이터 시각화 및 대시보드 구현** 경험을 쌓을 수 있었습니다.
