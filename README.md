#### 🔹 활동 배경:
상품 구매 전 리뷰가 소비자의 의사결정에 큰 영향을 미치지만, 방대한 리뷰 데이터 속에서 가짜 리뷰, 편향된 리뷰,
비정형 텍스트 정보를 사람이 직접 판단하기에는 시간, 노력 측면에서 한계가 있습니다.
이에 저희 조는 LLM 기반 Agent 시스템을 활용하여 상품 리뷰를 자동 분석하고, 리뷰 신뢰도 및 감성 분석 결과를 시각적으로
제공하는 AI 서비스를 구현하고자 프로젝트를 진행했습니다.
또한 Agent실행 흐름을 실시간으로 추적하고 성능을 개선할 수 있도록 LangSmith 기반 모니터링 환경 구축을 주요 목표로 설정했습니다.

<br>

#### 🔹 내가 맡은 역할:
- Streamlit을 통한 대시보드 기능 구현
- 발표 PPT 제작

<br>

#### 🔹 구체적인 활동:
- 대시보드에서 리뷰를 선택 시 해당 리뷰에 대한 분석결과와 피드백을 텍스트 형태로 제공
- 대시보드에서 리뷰를 선택 시 해당 리뷰에 대한 긍부정 데이터프레임과 막대 그래프를 제공함으로써 시각적 효과 구현
- 현재 리뷰나 과거 리뷰를 구분하지 않고 선택한 리뷰에 대한 전체 대시보드 동기화 작업
- 선택 리뷰에 대한 별점 및 긍부정 비율 시각적으로 구현
- LangSmith와 Streamlit을 통한 연계 및 실시간 추적

<br>

- 단순히 LLM API를 호출하는 수준을 넘어, **LangGraph 기반 Agent Workflow와 LangSmith 기반 실행 모니터링 환경**을 직접 경험하며 AI 서비스에서 Prompt 흐름 관리와 실행 로그 추적의 중요성을 체감할 수 있었고 디버깅 및 오류 분석 시간이 **약 30%** 단축되는 효과를 경험했습니다. (10분 -> 약 7분)

- Streamlit 기반 대시보드를 구현하며, 단순 데이터 출력이 아닌 **사용자에게 시각적으로 최적화된 형태로 데이터를 시각화하고 전달하는 UI/UX 설계 역량**을 향상시킬 수 있었습니다.

- 팀 프로젝트 과정에서 코드 병합 및 기능 통합 과정의 어려움을 경험하며,

#### 🔹 성과 및 배운 점:
- 풀스택 기반 환경 조성이 가능한 **Next.js를 활용**하여 다른 조와 차별점을 두었으며 이에 대한 결과로 다른 조보다 더 빠르게 프론트엔드와 백엔드를 동시에 구현할 수 있었습니다. 또한 두 환경을 동시에 관리함으로써 첫 페이지 로드 속도를 기존 대비 **약 25%** 단축하는 웹 성능 최적화 성과를 거두었습니다. **(1.2초 -> 약 0.9초)**

- 도서 관리 서비스 시나리오에 맞추어 기존의 단순한 임시 데이터베이스 구조를 실무 수준의 관계형 데이터베이스인 **MySQL로 안정적으로 전환**하였으며, 유연한 도서 데이터 수집과 무결성 유지가 가능하도록 테이블 간의 유기적인 관계를 정교하게 설계하고 정규화하는 역량을 길렀습니다.

- 웹 환경에서 즉각적인 API 테스트와 배포가 가능하도록 **Spring Boot 백엔드 서버**를 고도화하는 과정에서 **Controller-Service-Repository 계층형 아키텍처(MVC 패턴)** 를 엄격하게 적용해 보았으며, 기능 간 독립성을 확보하여 신규 기능 추가 시 기존 코드 수정 범위를 **10% 이하**로 억제하는 높은 유지보수성을 경험했습니다.

- 데이터 전송 계층과 데이터베이스 엔티티 계층을 확실하게 분리하는 **DTO 패턴을 프로젝트 전반에 도입**하였으며, 데이터 가공 및 응답 구조를 100% 분리함으로써 비즈니스 로직의 보안성을 한 단계 높이고 개발 단계에서의 불필요한 엔티티 노출 이슈를 **전부 해결(0건)** 하는 성과를 얻었습니다.

- 프론트엔드 UI 화면과 백엔드 API 서버가 실시간으로 끊김 없이 데이터를 주고받을 수 있도록 아키텍처 연동을 고도화하였으며, 통합 로컬 환경에서 모의 요청 테스트 성공률 **100%**를 달성하여 배포 준비 단계를 차질 없이 완성했습니다.

- **OpenAI GPT API 프롬프트를 연동**하여 사용자가 입력한 데이터에 어울리는 독창적인 커스텀 도서 표지를 실시간으로 생성해 내는 기능을 구현하였으며, AI 표지 생성 요청부터 DB 영속화(Save) 및 화면 렌더링까지의 전 과정을 **평균 20초 내외**로 처리하는 안정적인 인공지능 연동 프로세스를 완성했습니다. **(초기 전 과정 완료하는 데 걸린 시간 45초 -> 20초)**

- 도서 좋아요 데이터를 기반으로 **대시보드 내 실시간 인기 랭킹 사이드바를 동기화**하고 개인별 검색 히스토리를 추적하는 **연관 검색어 알고리즘**을 성공적으로 구현하였으며, 수천 건의 데이터 검색 상황에서도 연관 키워드를 **0.1초 이내**에 추천하는 초개인화 도서 탐색 경험을 완성했습니다.
